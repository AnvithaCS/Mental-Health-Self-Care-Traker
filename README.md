# Mental Health Self-Care Tracker

This project is a simple UI concept for a daily mental health tracker app. It helps users reflect on their mental well-being and build consistent self-care habits.

---

## Features

- **Mood Check-In**: Select your mood for the day (happy, sad, anxious, calm, etc.)
- **Gratitude Journal**: Space to write one thing you're thankful for
- **Energy Level**: Slider to track physical and emotional energy
- **Activity Tracker**: Mark basic habits like sleep, water, exercise, and screen time
- **Daily Affirmation**: A motivational message or quote
- **Mood History**: Calendar-style view of mood trends

---

## Tools Used

- Designed using Canva/Figma (or HTML/CSS if you coded it)
- Focused on **mental health awareness**, **habit-building**, and **self-reflection**
